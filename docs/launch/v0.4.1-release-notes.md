# React Native Image Compression Kit v0.4.1

This backward-compatible candidate fixes iOS pixel orientation and adds an
explicit lifecycle primitive for package-owned compression outputs.

## Highlights

- Preserve displayed pixel orientation after ImageIO normalizes EXIF
  orientations 1–8.
- Reject native demo captures whose output does not visually agree with the
  auto-oriented source or more closely matches a vertical flip.
- Add `removeCompressionOutput(uri)` for narrow, idempotent cleanup of one
  package-owned cache output.
- Keep foreign files, sources, traversal targets, symlinks, and directories
  outside the cleanup authority.
- Enforce live Dependabot vulnerability alerts and automatic security updates
  through the repository settings audit.

## Install after publication

```bash
npm install react-native-image-compression-kit@0.4.1
```

Until publication, npm `latest` remains 0.4.0. The 0.4.1 source candidate is
not represented as a registry release.

## Validation

- EXIF orientations 1–8 run through the default iOS decode, transform, and
  encode path and are compared with ImageIO's upright reference.
- The direct Core Graphics renderer preserves an asymmetric four-corner pixel
  fixture.
- Android and iOS demo capture measure auto-oriented SSIM and compare it with a
  vertical-flip control before evidence can be created.
- Existing JavaScript, native, documentation, supply-chain, compatibility, and
  package-shape gates remain required.

## Known limitations

- HEIC, HEIF, and AVIF output are not implemented.
- Animation preservation, batch compression, progress events, remote URLs, and
  data URIs remain outside scope.
- Native demo and benchmark captures are environment-bound observations, not
  universal speed or visual-quality claims.
